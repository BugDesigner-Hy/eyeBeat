# 切歌准星定位（Reticle Locate）设计

日期：2026-11-04
状态：已确认（决策见 `.superpowers/reticle-locate-decisions.md`），直接实现

## 目标

每次切歌（下一首 / 上一首 / 自动下一首 / 键盘 / 媒体键 / 点封面）时，一个像素风 HUD 准星从上一首的封面飞到新歌的封面：冲过头一点 → 左右晃一下 → 四角收紧锁定，锁定瞬间旁边闪 `LOCK` 小字、封面边框高亮闪一下。总时长约 0.75 秒（移动 0.45s + 晃动锁定 0.3s），无声音。

## 方案

选定：**单个 fixed 覆盖层组件 `CoverReticle.vue` + Web Animations API**。

- 挂在 `App.vue`，接收 `suspended`（`ui.detailOpen || ambient`），因为 `ambient` 只在 App 里计算。
- 准星由 4 个独立的角标 + 中心十字 + 标签组成，都是 `position: fixed; left: 0; top: 0` 的小盒子，只动画 `transform` / `opacity`。框的大小靠四个角各自平移表达，不用 `scale`，因此线宽不变形、不触发布局。
- 位置全部来自 `getBoundingClientRect`（视口坐标）：目标量 `.tile-inner`（视觉上的封面，含视差变换），起点量上一首的 `.tile-inner` 或底部播放器缩略图。
- 不碰 `CoverWall` 的视差：准星在独立覆盖层上；封面边框闪烁用 `data-lock` 属性 + `.tile-inner::after` 的 opacity 关键帧（Vue 不管理这个属性，不会被 `:class` 补丁冲掉；跟随视差一起移动）。

放弃的方案：
- 准星放进文档流随页面滚动：滚动距离大时视口内轨迹是两条曲线之差，会甩出屏幕。
- 原生 `scrollTo({ behavior: 'smooth' })`：时长和曲线不可控，没法和准星同步落位。

## 状态与流程

`watch(() => player.current?.id, (id, prevId), { flush: 'post' })`（DOM 已更新，`.is-current`、底栏都已渲染）：

1. 关闭开关 / 无新歌 → 取消进行中的动效，结束。
2. `suspended` 或 `document.hidden` → 记 `pending = true`，结束。恢复（`suspended` 变 false 延迟约 450ms 等详情页飞回动画；或页面重新可见）时若 `pending`，从底栏封面瞄准当前歌。没有挂起期间的切歌时开关详情页不触发。
3. 在 `.wall [data-track-id]` 里找新歌封面：
   - 找不到 → 屏幕右侧边缘闪两下 `NO TARGET`，不滚动。
   - 可见（在顶栏下沿到底栏上沿之间的面积 ≥ 50%）→ 不滚动，只飞准星。
   - 不可见且最近 3 秒内没有手动滚动 → 自定义滚动把封面滚到内容区中央附近（钳在可滚范围内），准星同时飞往“滚动结束后”的位置；滚动与移动同时长、同曲线，同时落位。
   - 不可见且最近手动滚动过 → 什么都不做。
4. 起点：动效进行中再次切歌时，取四个角当前的位置作为起点（无缝改道，不叠加）；否则上一首封面可见面积 ≥ 30% 用它；否则底栏缩略图（收起时用胶囊里的缩略图，没有则屏幕底部中央），钳进视口。
5. 移动阶段结束时重新量一次目标（视差缩放会随滚动变化），偏差用外层包裹元素的短 transform 动画补上，不改写正在跑的关键帧。

时间轴（ms）：0 起飞淡入 → 450 到达过冲点（沿飞行方向 ≈ 6% 距离，上限 28px），框比目标松 → 560 向左晃 → 650 向右回摆一半 → 750 四角收紧锁定、`LOCK` 闪、封面边框闪 → 保持 350 → 淡出 200。

## 手动滚动判定

监听 `wheel`、`touchmove`、滚动键（PageUp/PageDown/Home/End/↑/↓，且不在输入框里；空格被全局快捷键占用不会滚动）、滚动条或中键 `pointerdown`。这些输入会：记录时间戳；中断进行中的自定义滚动；准星快速淡出（页面一动 fixed 准星就脱靶了）。

## 边界情况

- 连点下一首：取消旧动画与滚动循环，从准星当前位置改道；只有一个覆盖层实例，不会叠加。
- 自动下一首发生在后台标签页：挂起，回到页面再瞄准（rAF 在隐藏页暂停，不在后台跑滚动循环）。
- 手机端（`useMobile()`）：同样行为，角标 9px、松框留白更小，`LOCK` 字号不变。手机上 `.tile` 下方有文字说明，因此量 `.tile-inner`。
- 减弱动效：需要时直接跳滚（instant），在目标处静态显示锁定框约 700ms（阶梯式出现 / 消失，无飞行无晃动）；离墙时静态边缘框。
- 开关：`settings.reticleLocate`，默认开。FX 面板底部加 `[准星 ON/OFF]`，命令面板 VISUAL 组加「切歌准星定位」。
- 卸载：取消动画、滚动循环、计时器和所有监听。

## 验证

- `pnpm exec vue-tsc --noEmit`、`pnpm build`。
- 浏览器 1920×1080、1366×768、390×844：等动画结束后比较准星四角外框与 `.tile-inner` 的 rect；目标可见时 `scrollY` 不变；目标不可见时滚到中央附近；滚轮后 3 秒内切到不可见目标不滚动；搜索/非本墙曲目时出现边缘 `NO TARGET`；详情页开着切歌不动、关闭后瞄准；连点三次只有一个准星且落在最后一首；减弱动效（CDP 模拟）静态框；开关关闭无动效。
