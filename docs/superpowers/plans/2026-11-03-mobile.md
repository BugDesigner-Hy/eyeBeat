# 手机端交互与显示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 640px 以下提供原生 App 式的手机体验（两列首页、菜单抽屉、迷你播放条、三页滑动详情页），桌面端不变。

**Architecture:** 新增模块级单例 `useMobile()`（`matchMedia('(max-width: 640px)')`）统一判定行为差异，样式差异用同一断点的媒体查询。新组件 `MobileSheet`、`MobileBar` 只在手机端渲染；`NowPlaying` 在手机端切换为横向 `scroll-snap` 分页结构并复用现有子组件。

**Tech Stack:** Vue 3.5（`<script setup>`）、TypeScript 5.9 strict（含 noUnusedLocals / noUnusedParameters）、Pinia、Vite 8、pnpm。

## Global Constraints

- 只用 pnpm，不用 npm。类型检查：`pnpm exec vue-tsc --noEmit`；构建：`pnpm build`。
- Windows PowerShell：命令用 `;` 串联，不用 `&&`。
- 断点固定为 `640px`：CSS 写 `@media (max-width: 640px)`，脚本用 `useMobile()`，两者必须一致。
- 桌面端（宽度 > 640px）的布局与交互不得改变。
- 设计 token：`--accent`、`--text`、`--text-dim`、`--line`、`--line-strong`、`--bg`、`--ease-out: cubic-bezier(0.16, 1, 0.3, 1)`、`--ease-in: cubic-bezier(0.7, 0, 0.84, 0)`；字体 `--font-pixel`（Silkscreen，只有拉丁字符）、`--font-mono`（VT323）、`--font-sans`。
- 手机端可点区域不小于 44×44。
- 减弱动效：全局已有规则把动画/过渡时长压到 0.01ms；新增的 JS 平滑滚动要在 `prefers-reduced-motion: reduce` 时改为 `'auto'`。
- z-index：详情页 55、扫描线 56、FX 57、替身 58、toast 60、命令面板 90、菜单抽屉 92、登录弹窗 95、扫描线罩层 100。
- 代码注释只写代码本身表达不了的约束，用中文，风格与现有代码一致。
- 项目没有单元测试框架；每个任务的验证是类型检查 + 由控制者在浏览器 390×844 下检查（实现者跳过浏览器步骤）。

let drag: { id: number; y: number } | null = null

function onGrab(e: PointerEvent) {
  drag = { id: e.pointerId, y: e.clientY }
  try {
    ;(e.currentTarget as HTMLElement).setPointerCapture(e.pointerId)
  } catch {}
}

function onGrabMove(e: PointerEvent) {
  if (drag?.id === e.pointerId) dragY.value = Math.max(0, e.clientY - drag.y)
