# 详情页评论区 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 详情页对有评论的歌曲展示只读评论（热门 + 最新、无限下滑加载），桌面 ≥1440px 为第三栏、<1440px 为抽屉，手机端为第 4 页。

**Architecture:** `MusicProvider` 增加可选的 `getComments(track, cursor?)`，网易云与 Audius 各自把评论映射成统一的 `TrackComment` / `CommentPage`，游标由各源自行编码。新 store `comments` 按 `provider:trackId` 缓存（最多 20 首），负责第一页加载、翻页去重和切歌后的过期结果丢弃，并给出 `visible`（规格定义）与 `present`（是否给评论区留位，切歌加载期间沿用原值防闪烁）。展示由 `DetailComments.vue`（列表、分区、底部状态、IntersectionObserver 哨兵）+ `CommentItem.vue`（单条，Audius 楼中楼递归）组成，`NowPlaying.vue` 按断点把它放进第三栏、抽屉或手机第 4 页。

**Tech Stack:** Vue 3.5（`<script setup>`）、TypeScript 5.9 strict（含 noUnusedLocals / noUnusedParameters）、Pinia、Vite 8、pnpm。

**Spec:** `docs/superpowers/specs/2026-11-04-comments-design.md`

## Global Constraints

- 只用 pnpm。类型检查：`pnpm exec vue-tsc --noEmit`；构建：`pnpm build`。
- Windows PowerShell：命令用 `;` 串联，不用 `&&`。
- 项目没有单元测试框架。每个任务的验证 = 类型检查 + 在 dev 服务器 `http://localhost:5173`（`pnpm dev`，网易云走 `/ncm` 代理）的浏览器控制台里执行给出的片段并核对预期结果。
- 非目标：发表评论、点赞、展开楼中楼、登录相关的评论能力。
- 评论内容只当纯文本渲染，禁止 `v-html`。
- 网易云接口：热门 `comment/new?type=0&id=&sortType=2&pageNo=1&pageSize=10`；最新 `comment/new?type=0&id=&sortType=3&pageSize=20&pageNo=n&cursor=`（第一页不带 cursor）。沿用 `ncm()` 现有的 cookie / `noCookie` / `session` 逻辑，不额外处理。
- Audius 接口：`${BASE}/tracks/{id}/comments?limit=&offset=&sort_method=top|newest&app_name=hiMusic`；热门 `limit=10`，最新 `limit=20`；返回条数少于 limit 视为结束；跳过 `is_tombstone` 的评论；总数取曲目对象的 `comment_count`。
- 缓存最多保留最近 20 首；请求返回时若曲目已切换，丢弃结果。
- `visible`：音乐源支持、第一页已返回、且热门加最新至少 1 条。加载中和出错时不显示（第一页出错整块隐藏，不提示）。
- 桌面三栏（宽度 ≥ 1440px）：`grid-template-columns: min(44vh, 40vw) minmax(0, 1fr) clamp(300px, 22vw, 380px)`；抽屉宽度同第三栏。
- 抽屉按钮文案 `[CMT 69]`，总数未知时 `[CMT]`。Esc 优先级：菜单 → 评论抽屉 → 详情页 → FX。切歌、关闭详情页时抽屉收回。
- 手机端（≤ 640px）分页 `01 PLAY · 02 LRC · 03 INFO · 04 CMT`；`DetailPage = 0 | 1 | 2 | 3`；页码下划线每页 68px 不变。手机端 640px 的媒体查询块必须放在 `<style>` 的末尾。
- 头像 28px，`image-rendering: pixelated`；网易云头像加 `?param=32y32`，Audius 用 `profile_picture['150x150']`。
- 无限加载：IntersectionObserver 观察底部哨兵，root 为评论列表自身（手机端为第 4 页），`rootMargin` 底部提前 400px。
- 新加载的一页逐条淡入（沿用 `.np-in`），只对新追加的条目；减弱动效时不做淡入（全局 `.np-in` 规则已处理）。
- 设计 token：`--accent`、`--text`、`--text-dim`、`--line`、`--line-strong`、`--bg`、`--bg-2`、`--ease-out`；字体 `--font-pixel`（Silkscreen）、`--font-mono`（VT323）、`--font-sans`。
- 代码注释只写代码本身表达不了的约束，用中文，密度与现有代码一致。

```ts
interface NeteaseComment {

  content?: string | null
  /** 毫秒时间戳 */
  time: number
  timeStr?: string
  likedCount?: number
  ipLocation?: { location?: string } | null

  data?: {

function toComment(c: NeteaseComment): TrackComment {
  const r = c.beReplied?.[0]
  const avatar = c.user?.avatarUrl
  return {
    id: String(c.commentId),
    user: { name: c.user?.nickname || '匿名', avatar: avatar ? `${https(avatar)}?param=32y32` : undefined },
    content: c.content ?? '',
    time: c.time,
    timeLabel: c.timeStr || undefined,
    likes: c.likedCount ?? 0,
    location: c.ipLocation?.location || undefined,
    replyTo: r?.user?.nickname && r.content ? { user: r.user.nickname, content: r.content } : undefined,
  }
}

/** sortType：2 热门，3 最新 */
function commentList(id: string, sortType: 2 | 3, pageNo: number, pageSize: number, cursor?: string) {
  return ncm<CommentRes>('/comment/new', { type: 0, id, sortType, pageNo, pageSize, cursor })
```

```ts
  async getComments(track, cursor) {
    const [no = '1', cur] = cursor?.split(':') ?? []
    const pageNo = Number(no)
    const [hot, latest] = await Promise.all([
      cursor ? null : commentList(track.id, 2, 1, HOT_COMMENTS).catch(() => null),
      commentList(track.id, 3, pageNo, COMMENT_PAGE, cur),

    const d = latest.data
    const items = (d?.comments ?? []).map(toComment)
    return {
      hot: hot ? (hot.data?.comments ?? []).map(toComment) : undefined,
      items,
      next: d?.hasMore && items.length && d.cursor != null ? `${pageNo + 1}:${d.cursor}` : null,

  },
```

```ts
const COMMENT_PAGE = 20

interface AudiusComment {
  id: string
  user_id: string
  message: string
  react_count?: number
  /** ISO 时间 */
  created_at: string
  track_timestamp_s?: number | null
  reply_count?: number
  replies?: AudiusComment[] | null
  is_tombstone?: boolean
}

interface AudiusUser {
  id: string
  name?: string
  handle?: string
  profile_picture?: Partial<Record<ArtworkSize, string>> | null
}

interface CommentsRes {
  data?: AudiusComment[]
  related?: { users?: AudiusUser[] }
}

function commentList(id: string, sort: 'top' | 'newest', limit: number, offset: number) {
  return getJson<CommentsRes>(
    `${BASE}/tracks/${encodeURIComponent(id)}/comments?${qs({ limit, offset, sort_method: sort, app_name: APP_NAME })}`,
  )
}

/** 评论列表接口不返回总数，取曲目对象上的 comment_count */
function commentCount(id: string): Promise<number | undefined> {
  return getJson<{ data?: AudiusTrackDetail }>(`${BASE}/tracks/${encodeURIComponent(id)}?${qs({ app_name: APP_NAME })}`)
    .then((r) => r.data?.comment_count)
    .catch(() => undefined)
}

function toComments(res: CommentsRes): TrackComment[] {
  const users = new Map((res.related?.users ?? []).map((u) => [u.id, u]))
  const map = (c: AudiusComment): TrackComment => {
    const u = users.get(c.user_id)
    const replies = c.replies?.filter((r) => !r.is_tombstone).map(map)
    return {
      id: c.id,
      user: { name: u?.name || u?.handle || 'Unknown', avatar: u?.profile_picture?.['150x150'] },
      content: c.message,
      time: Date.parse(c.created_at) || 0,
      likes: c.react_count ?? 0,
      replies: replies?.length ? replies : undefined,
      replyCount: c.reply_count || undefined,
      at: c.track_timestamp_s ?? undefined,
    }
  }
  return (res.data ?? []).filter((c) => !c.is_tombstone).map(map)
}
```

- [ ] **Step 4: 创建 `src/stores/comments.ts`**

```ts
import { defineStore } from 'pinia'
import { computed, reactive, ref, watch } from 'vue'
import { provider } from '../api'
import type { Track, TrackComment } from '../api/types'
import { usePlayerStore } from './player'
import { useUiStore } from './ui'

const MAX_CACHED = 20

export interface CommentThread {
  hot: TrackComment[]
  items: TrackComment[]
  /** 下一页游标，null 表示没有更多 */
  next: string | null
  total?: number
  /** 第一页已返回 */
  ready: boolean
  loading: boolean
  /** 最近一次请求失败：第一页失败时整块隐藏，翻页失败时显示重试 */
  error: boolean
}

const keyOf = (t: Track) => `${t.provider}:${t.id}`

export const useCommentsStore = defineStore('comments', () => {
  const player = usePlayerStore()
  const ui = useUiStore()
  const supported = !!provider.getComments
  /** Map 的插入顺序即最近使用顺序，超出上限时从头淘汰 */
  const cache = reactive(new Map<string, CommentThread>())

  const thread = computed(() => (player.current ? cache.get(keyOf(player.current)) : undefined))
  const total = computed(() => thread.value?.total)
  const visible = computed(() => !!thread.value?.ready && thread.value.hot.length + thread.value.items.length > 0)
  /** 详情页开着、当前曲目的第一页还没回来（含尚未发出请求的那一瞬） */
  const pending = computed(() => {
    const t = thread.value
    return supported && ui.detailOpen && !!player.current && (!t || (t.loading && !t.ready))
  })
  /** 是否给评论区留位置；切歌后新曲目第一页加载期间沿用原值，避免栏位和分页闪一下 */
  const present = ref(false)
  watch(
    [visible, pending, () => ui.detailOpen],
    ([v, p, open]) => {
      if (v && open) present.value = true
      else if (!p) present.value = false
    },
    { immediate: true },
  )

  const isCurrent = (key: string) => !!player.current && keyOf(player.current) === key

  async function loadFirst(track: Track) {
    if (!provider.getComments) return
    const key = keyOf(track)
    const hit = cache.get(key)
    cache.delete(key)
    if (hit && (hit.ready || hit.loading)) {
      cache.set(key, hit)
      return
    }
    cache.set(key, { hot: [], items: [], next: null, ready: false, loading: true, error: false })
    for (const k of cache.keys()) {
      if (cache.size <= MAX_CACHED) break
      cache.delete(k)
    }
    const t = cache.get(key)!
    try {
      const page = await provider.getComments(track)
      if (!isCurrent(key)) {
        if (cache.get(key) === t) cache.delete(key)
        return
      }
      t.hot = page.hot ?? []
      t.items = page.items
      t.next = page.next
      t.total = page.total
      t.ready = true
    } catch {
      if (isCurrent(key)) t.error = true
      else if (cache.get(key) === t) cache.delete(key)
    } finally {
      t.loading = false
    }
  }

  async function loadMore() {
    const track = player.current
    const t = thread.value
    if (!track || !t || !provider.getComments || !t.ready || t.loading || t.error || !t.next) return
    const key = keyOf(track)
    t.loading = true
    try {
      const page = await provider.getComments(track, t.next)
      if (!isCurrent(key)) return
      const seen = new Set(t.items.map((c) => c.id))
      t.items = [...t.items, ...page.items.filter((c) => !seen.has(c.id))]
      t.next = page.next
    } catch {
      if (isCurrent(key)) t.error = true
    } finally {
      t.loading = false
    }
  }

  function retry() {
    if (thread.value) thread.value.error = false
    return loadMore()
  }

  // 只在详情页开着时请求，切歌时跟着换
  watch(
    () => [ui.detailOpen, player.current] as const,
    ([open, track]) => {
      if (open && track) void loadFirst(track)
    },
    { immediate: true },
  )

  return { thread, total, visible, present, loadMore, retry }
})
```

```ts
/** 与网易云 timeStr 同风格的相对时间；超过 30 天显示日期 */
export function relTime(ms: number, now = Date.now()): string {
  if (!ms) return ''
  const m = Math.floor((now - ms) / 60000)
  if (m < 1) return '刚刚'
  if (m < 60) return `${m}分钟前`
  if (m < 1440) return `${Math.floor(m / 60)}小时前`
  if (m < 43200) return `${Math.floor(m / 1440)}天前`
  const d = new Date(ms)
  return `${d.getFullYear()}-${String(d.getMonth() + 1).padStart(2, '0')}-${String(d.getDate()).padStart(2, '0')}`
}
```

## 规格中的模糊点与本计划的取舍

- 缓存字段 `done`：规格未定义含义。本计划用 `ready` 表示「第一页已返回」，「没有更多」由 `next === null` 表达，不再单设字段。
- 切歌闪烁：规格的 `visible` 在新曲目加载期间为假，会让第三栏、按钮和手机第 4 页闪一下，且「停在第 4 页切到有评论的歌」也会被踢回第 3 页。新增 `present`：当前曲目第一页加载中沿用原值，第一页返回后再按 `visible` 定；详情页关闭时清零。`visible` 本身保持规格定义。
- 第一页过期结果：丢弃并删除该缓存条目，回到这首歌时重新请求（`ncm` 有 2 分钟服务端缓存）；翻页过期结果丢弃但保留已有条目。
- 抽屉关闭方式：除按钮与 Esc 外，增加点击抽屉外遮罩关闭（641–900px 的平板没有 Esc，且该区间头部会随内容滚走）；头部提到抽屉之上，按钮始终可点。跨越 1440 / 640 断点时抽屉也收回。
- 热门请求失败：只省略热门段，不算第一页失败；最新请求失败才整块隐藏。
- 网易云回复引用：只有被回复者昵称和内容都非空时才显示（原评论被删时不显示引用块）。
- Audius 总数：Track 映射没有保留 `comment_count`，第一页额外请求 `/tracks/{id}` 取总数，失败时总数缺省（按钮显示 `[CMT]`）。
- Audius 相对时间：前端按网易云 `timeStr` 的中文风格生成（刚刚 / N分钟前 / N小时前 / N天前），超过 30 天显示 `YYYY-MM-DD`。
- 点赞数为 0 时不显示心形和数字。
- 头像失败占位：强调色调的方块里显示昵称首字（大写）。
- `LOADING…`：沿用项目现有的 `.dots` 逐帧省略号写法。
- 第三栏只做入场动画，不做离场（离场时栅格已变回两栏，留着会被挤到下一行）。
- 计数格式：评论总数和点赞数用从 `DetailInfo.vue` 提出的 `fmtNum`（`1.6M` / `12.3K` / `1,234`），按钮即 `[CMT 1.6M]`。
